## 🚀 安装指南

### 环境要求
- Python 3.10+
- Ollama（用于AI聊天）
- **NapCat**（QQ协议适配，**唯一支持框架**）
- ffmpeg（用于语音转换，可选）

### 1. 克隆项目
```bash
git clone https://github.com/xp12-mcmin/qq-robot.git
cd qq-robot
```

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

核心依赖：
```bash
pip install websockets aiohttp flask requests pillow psutil
```

### 3. 安装 ffmpeg（用于语音转换，可选）

**Windows:**
- 下载：https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
- 解压后将 `bin/ffmpeg.exe` 复制到项目目录

**Linux:**
```bash
sudo apt install ffmpeg
```

**macOS:**
```bash
brew install ffmpeg
```

### 4. 安装 Ollama
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

拉取模型：
```bash
ollama pull qwen2.5:3b
```

### 5. 配置 NapCat

| 配置项 | 值 |
|--------|-----|
| WebSocket 端口 | `8765` |
| HTTP API 端口 | `3000` |
| QQ 版本 | **9.9.26（不要升级到 9.9.31+）** |

> ⚠️ **重要：** QQ 9.9.31+ 与 NapCat 不兼容，请锁定版本。

### 6. 运行机器人
```bash
python qai主程序.py
```

### 7. 可选：独立点歌模块
```bash
python music_bot.py
```

```python
# AI模型配置
self.text_models_priority = ["qwen2.5:3b", "qwen2.5:1.5b"]

## 🔒 安全规则

- 敏感词过滤（涉黄自动拦截）
- 辱骂机器人检测（自动拉黑）
- 5次违规自动拉黑
- 30分钟无违规重置计数
## 🛡️ 安全机制

本项目内置双进程看门狗：
- 检测到 LLBot 进程 → 自动清除
- 看门狗A被关闭 → 看门狗B自动重启
- 窗口关闭按钮被禁用，无法手动退出
